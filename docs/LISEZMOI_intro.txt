ShroudInFrench — complément « Intro VF »
========================================

Ce fichier optionnel ajoute une narration française et un accompagnement stéréo remanié à l'introduction d'Enshrouded.
Il complète l'archive principale « ShroudInFrench » ; il ne la remplace pas. L'archive PNJ reste indépendante.

INSTALLATION MANUELLE AVEC EML
------------------------------
1. Fermez Enshrouded.
2. Décompressez « ShroudInFrench_Intro_EML.zip » dans le dossier du jeu. Le dossier créé est :
   mods\ShroudInFrenchIntro\
3. Lancez le jeu avec la configuration EML habituelle, ou exécutez :
   emm.exe run -p -f -g "<dossier du jeu>"
4. Dans Options → JEU → « Langue du doublage », sélectionnez « Français (VF) ».

Le complément remplace uniquement la piste de narration chinoise de l'introduction. Les langues anglaise et allemande restent disponibles.

DÉSINSTALLATION
---------------
- Pour retirer uniquement l'intro : fermez le jeu, supprimez mods\ShroudInFrenchIntro\, puis lancez emm.exe run -p -f -g "<dossier du jeu>" pour reconstruire le patch avec les autres mods.
- Pour tout retirer : supprimez mods\ShroudInFrenchIntro\ et suivez les instructions de désinstallation de l'archive principale. Ne lancez pas emm.exe restore s'il reste d'autres mods EML.

Ce complément requiert une version du jeu et d'EML compatibles avec l'archive principale. La piste utilise la voix française de l'intro déjà présente dans le projet, au timbre de Damien, et le format audio stéréo natif du jeu.
